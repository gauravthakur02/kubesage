# Code of conduct

kubesage follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be kind and respectful, assume good intent, welcome newcomers, and keep criticism about the work, not the
person. Harassment, insults, discrimination and publishing others' private information are not tolerated, in issues,
pull requests, discussions or anywhere else the project is represented.

**Reporting:** if someone's behaviour worries you, report it privately to the maintainer through GitHub's private
reporting (the repository's **Security** tab → **Report a vulnerability**, and say it is a conduct report), or by a
direct message to the maintainer on GitHub. Reports are handled confidentially. Maintainers may remove comments,
close issues or block people who break this code of conduct.
